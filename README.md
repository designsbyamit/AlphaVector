# AlphaVector

Three signals, one fix on your calling. This repository holds two separate projects:

- `alphavector-site/` the public site: framework, method, resources and workshop enquiries.
- `alphavector-app/` the app: log your projects, assess strengths, specify passion, pick a niche and get your Future Blueprint.

Each deploys as its own Vercel project (set the root directory to the folder). See the README in each folder.
